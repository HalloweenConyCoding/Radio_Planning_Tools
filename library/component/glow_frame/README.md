# Cony Glow Frame

Vanilla, no-build glowing perimeter for local pages. Load `glow-frame.css` and `glow-frame.js`, add `cony-glow-frame`, and use `data-glow-mode="auto"` for a CSS sweep or `cursor` for pointer tracking.

`mount(root)` returns a `destroy()` cleanup handle. The component has no React, npm, CDN, or server dependency.
